# Пульс новичка

**Демо:** https://v0olker.github.io/pulse-novichka/ — открывается в браузере без установки. Сценарий: «📱 Опрос глазами новичка» → ответить «Намного тяжелее, долго не выдержу» → «Посмотреть, что увидел HR».

Короткие опросы нового сотрудника в первые 90 дней, светофор риска для HR и автоматические задачи руководителю в Битрикс24, когда нужен живой разговор.

**Для кого:** HR (видит всех новичков и где горит) и линейные руководители: начальники смен склада, директора магазинов, руководитель отдела продаж. Они получают задачу «поговорить» с подсказкой, о чём говорить. Новичок — источник сигнала: 30 секунд с телефона по личной ссылке, без логина.

## Как работает

1. Сотрудник принят. В рабочей версии это закрытие задачи «Приём» в Битрикс24 (сейчас — форма «Добавить новичка»).
2. На 3, 7, 14, 30, 60 и 85-й день работы новичку открывается опрос из 3–4 вопросов: встретили ли, есть ли наставник, нагрузка как договаривались, зарплата как ожидали, говорил ли руководитель, видит ли себя у нас через полгода.
3. Каждый ответ даёт статус:
   - **красный** — есть критичный ответ;
   - **жёлтый** — есть тревожный ответ, настроение упало или новичок не отвечает дольше 3 дней;
   - **зелёный** — всё в порядке.
4. Задача в Битрикс24 (`tasks.task.add`) создаётся только когда нужен разговор:
   - критичный ответ → руководителю, срок завтра;
   - одна и та же проблема два опроса подряд → руководителю, срок 3 дня;
   - сигнал про руководителя или просьба «хочу поговорить с HR» → задача **HR**, не руководителю;
   - в задаче есть подсказки к разговору по каждой теме;
   - комментарий новичка видит только HR.
5. Руководитель или HR закрывает задачу с итогом («проблему устранили», «уходит»…). Новичок становится «отработанным» до следующего опроса.

Правила лежат в одном файле: [public/shared/logic.js](public/shared/logic.js). Его используют и сервер, и браузер.

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет.

```bash
npm start                # http://localhost:3000
npm test                 # 14 тестов: правила + сквозной тест сервера с поддельным Битрикс24
```

Переменные окружения:

| Переменная | Что делает |
|---|---|
| `PORT` | порт, по умолчанию 3000 |
| `BITRIX_WEBHOOK_URL` | входящий вебхук портала, например `https://ваш-портал.bitrix24.ru/rest/1/xxxxxxxx/`, с правом «Задачи». Без него задачи не отправляются, а в интерфейсе видно, что ушло бы в Битрикс24 |
| `DATA_FILE` | путь к файлу состояния, по умолчанию `data/state.json` |

При первом запуске создаются демо-данные: 26 вымышленных новичков на складе, в 3 магазинах, оптовом отделе и офисе. Сбросить их можно на странице «Как устроено».

### Два режима

- **Сервер** (`npm start`):
  - новичок отвечает по личной ссылке `/s/<token>` с любого телефона и видит только свой опрос;
  - HR смотрит доску у себя.
- **Демо без сервера:** если открыть `public/` как статический сайт, приложение само переходит в демо-режим.
  - Данные хранятся в браузере.
  - Роль новичка открывается через «Опрос глазами новичка».
  - Так устроена опубликованная демо-ссылка.

### Деплой

Подходит любой хостинг с Node: Render, Railway, VPS. Есть `Dockerfile`. На Render: Web Service, команда запуска `node server.js`. Для сохранения данных нужен постоянный диск, путь к нему задаётся в `DATA_FILE`.

## Ограничения (честно)

- **Нет входа для HR.** Доска и `/api/state` открыты всем, у кого есть адрес. Перед реальными данными нужен вход через Битрикс24 (OAuth локального приложения).
- **Рассылки нет.** Ссылку новичку сейчас передают вручную. Нужно SMS, Telegram или WhatsApp, либо уведомление через Битрикс24.
- **Битрикс24 работает в одну сторону.** Задачи создаются, но закрытие задачи в Битриксе обратно не подтягивается, итог отмечают в приложении. Приём сотрудника из Битрикса не подключён.
- **Работа с портала не проверялась.** Отправка проверена только на поддельном сервере. ID пользователей Битрикс24 вымышлены, часовой пояс дедлайна зашит как МСК.
- **Пороги светофора — экспертная догадка.** Их нужно сверить с реальными увольнениями.
- **Хранилище — JSON-файл.** Для 100–150 новичков в год этого хватает, для большего нужна база данных.

## Структура

```
server.js              HTTP-сервер, хранение, отправка в Битрикс24
public/index.html      вход
public/app.js          интерфейс: доска HR, карточка, задачи, опрос
public/store.js        хранилище: сервер или демо в браузере
public/shared/logic.js вопросы, контрольные точки, светофор, правила задач, формат tasks.task.add
public/shared/seed.js  синтетические данные (вымышленные люди)
test/                  node:test
```
